# External Case Analysis Template

외부 조경 사례를 단순 레퍼런스 이미지로 수집하는 것이 아니라, **내 설계 언어(Design Language) 체계로 해석·재분류**하기 위한 분석 템플릿이다.  
분석 목적은 스타일 모방이 아니라 **공간 구조·경험 전략·운영 가능성**을 추출하여, 오피스 본사·데이터센터·병원·주상복합 프로젝트에 적용 가능한 인사이트로 전환하는 데 있다.

## 3. Design Language Mapping

외부 사례에 적용된 설계 언어를 분석한다.  
아래 10개 항목 중 해당되는 언어를 선택하고, **증거 기반으로 해석**한다.

- Controlled Curve
- Curved Transition
- Sculpted Ground
- Signature Pause
- Spatial Relief
- Layered Experience
- Urban Canopy
- Linear Forest
- Framed Nature

| Quiet Resort |  |  |  | 예: Signature Pause |

### 3-2. 해석 가이드
- **적용 여부 정의**
  - ●: 공간 정체성을 주도하는 핵심 언어
  - ○: 명확히 확인되는 보조 언어
  - △: 부분적/제한적 적용
  - X: 해당 없음
- **분석 원칙**
  1. 형태 유사성보다 **공간 작동 원리**를 우선 기록한다.
  2. 단일 언어가 아니라 **언어 간 관계(지원/강화/확장/생성)**를 함께 해석한다.
  3. 감성 표현은 반드시 동선·식재·레벨·구조물 등 **물리적 근거**와 연결한다.
